# Custom Nodes Example: Motor Control and Hardware Peripherals

This directory contains a complete, runnable example demonstrating how to define, implement, compile, and execute custom board nodes in LogicElements.

---

## Overview

The example models an industrial motor drive system featuring three specialized microcontroller hardware peripherals:

## Registered custom nodes

| Type | Function ID | Role |
| :--- | :--- | :--- |
| `BOARD_PWM` | `0x81` (129) | Hardware PWM timer channel (TIM1) controlling motor speed from a filtered float duty cycle (`0.0%` to `100.0%`). |
| `BOARD_ENCODER` | `0x82` (130) | Hardware quadrature encoder counter (TIM3) tracking motor shaft angle with a zero-index reset input. |
| `BOARD_FILTER` | `0x83` (131) | Single-pole exponential low-pass filter smoothing raw analog speed potentiometer readings. |

> All custom-node function ids are `>= LE_FUNC_CUSTOM_BASE (0x80)`, so the runtime
> dispatches them to the board HAL `ext_call`. Custom nodes are emitted as
> `LE_OP_BLOCK` calls; the actual disassembly (opcodes + arity + operands) is
> generated by running the example, e.g. `py examples/custom_nodes/run_example.py`
> or `le_compile ... -d disasm.txt`.

---

## Files in this example

| File | Description |
| :--- | :--- |
| `custom_board.leconfig` | Board hardware profile declaring memory limits, pin aliases, and custom node metadata. |
| `motor_control_circuit.json` | Circuit schematic wiring pushbuttons, latch logic, and custom hardware peripheral nodes. |
| `custom_nodes.h` | C header file declaring peripheral driver functions (automatically included in exported headers). |
| `custom_hal.c` | Production-ready C implementation of `ext_call` and `get_custom_nodes_json` for the board HAL. |
| `run_example.py` | Python script that compiles the circuit, disassembles the binary, and verifies the `LE_OP_BLOCK` custom-node calls (`fn:0x81/0x82/0x83`). |

## How to run the example

### Option 1: Using the Python runner
```bash
py examples/custom_nodes/run_example.py
```

### Option 2: Using the `le_compile` CLI executable
```bash
# Compile and generate a disassembly listing:
./build/Release/le_compile examples/custom_nodes/motor_control_circuit.json \
    -b examples/custom_nodes/custom_board.leconfig \
    -o motor_control.lebin \
    -d disasm.txt \
    --stats
```

### Option 3: Exporting a standalone embedded C header
```bash
# Generates a C static array embeddable in ROM:
./build/Release/le_compile examples/custom_nodes/motor_control_circuit.json \
    -b examples/custom_nodes/custom_board.leconfig \
    -c motor_control_program.h
```

## Microcontroller integration

To integrate these custom nodes into target firmware:

1. Copy `custom_nodes.h` and `custom_hal.c` to your board's project directory.
2. In your startup code, register the callbacks into your `le_hal_t` instance:
   ```c
   custom_board_register_hal_callbacks(&my_board_hal);
   ```
3. When technicians run the `nodes` command in `le_cli` or host tools send binary command `0x03`, the board automatically reports its custom node capabilities.
